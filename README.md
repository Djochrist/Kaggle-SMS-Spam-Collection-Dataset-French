> Version française traduite d’un corpus anglophone de messages SMS classés comme spams ou messages légitimes.

## Présentation

Ce dataset a été créé pour faciliter l’entraînement et l’évaluation de modèles d’intelligence artificielle capables de détecter automatiquement les messages indésirables en français.

Il s’appuie sur un corpus anglophone existant dont les messages ont été traduits en français. Cette approche permet de rendre accessible une base de données francophone pour les premiers travaux de classification de textes et de détection des spams.

## Catégories

Chaque message appartient à l’une des deux catégories suivantes :

- `spam` : message indésirable ou non sollicité ;
- `ham` : message légitime, également appelé message normal.

## Utilisations possibles

Ce dataset peut servir à :

- entraîner un premier modèle de classification ;
- tester des algorithmes de traitement automatique du langage ;
- comparer différentes méthodes de détection des spams ;
- créer des prototypes et des démonstrations ;
- expérimenter avec des modèles de machine learning en français ;
- effectuer des tests de préparation et de nettoyage de données.

## Limites

Les messages ont été traduits depuis une langue source. Ils ne représentent donc pas nécessairement les formulations naturellement utilisées par les francophones.

Les traductions peuvent également contenir :

- des tournures peu naturelles ;
- des expressions influencées par l’anglais ;
- des différences culturelles ou contextuelles ;
- une diversité limitée des styles d’écriture ;
- des formulations éloignées des spams réellement reçus en français.

Les résultats obtenus avec ce dataset doivent être interprétés avec prudence. Il est recommandé de compléter l’évaluation avec des messages français naturels, anonymisés et légalement obtenus.
